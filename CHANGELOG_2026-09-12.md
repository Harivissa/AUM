# AUM — 2026-09-12 Product Expansion

## Product architecture
- Home is now an AUM introduction + immersive 3D universe rather than a long scroll of every knowledge section.
- Primary navigation opens dedicated internal chambers through hash routes.
- Itihāsa opens a dedicated index, then separate Rāmāyaṇa and Mahābhārata chambers.
- Purāṇa has a dedicated page indexing all 18 Mahāpurāṇas.
- Devatā has a dedicated interactive gallery.
- Smṛti is a unified chamber for Hindu tolerance/pluralism, civilizational memory, attacks on Hindus and Love Jihad material.
- Young Seekers is a dedicated chamber.
- AUM Verify, Tīrtha, Śāstra, Dharma and Explore each have dedicated routes.

## Young Seekers visual update
The three provided devotional reference images supplied with the project were incorporated into the Young Seekers and Devatā experiences as image assets:
- Bāla Gopāla
- Śrī Kṛṣṇa
- Śrī Gaṇeśa

These are the supplied visual assets, not newly generated photographs. If photographic temple/statue assets are desired later, replace these files with properly licensed photos.

## Languages
The interface language selector supports:
- System Default
- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam
- Marathi
- Sanskrit

The selector persists locally and updates the document language. Core navigation labels are translated; source texts and long-form knowledge content intentionally retain their authored language/Sanskrit where a full translation has not been authored yet.

## 3D / visual atmosphere
- Added floating Sanskrit elements, white/gold light particles and depth glows to the home experience.
- Preserved the central ॐ + mandala navigation concept.
- Added richer home identity panels without turning Home into the old long-form content dump.

## Epic family trees
Both Rāmāyaṇa and Mahābhārata relationship trees now use a fixed, clipped viewport. The tree itself cannot create page-level horizontal scrolling. Node positions were rebalanced and additional relationship context was added to the Mahābhārata tree.
