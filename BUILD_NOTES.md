# AUM — End-to-End 3D Sanātana Knowledge System

This build keeps the existing AUM visual language and upgrades the experience around the central 3D AUM/Mandala universe.

## Included
- Central interactive 3D ॐ mandala with seven sacred portal nodes.
- Custom 3D portal geometry for ŚRUTI, ITIHĀSA, PURĀṆA, DARŚANA, ĀGAMA, BHAKTI and AUM VERIFY.
- Slow idle rotation, mouse/touch rotation, node hit targets and responsive spacing.
- Full-screen 3D universe mode.
- Floating Sanskrit atmosphere.
- Sacred geography / Kṣetra atlas.
- Śāstra library and Itihāsa preview.
- Dedicated internal Rāmāyaṇa and Mahābhārata pages with interactive relationship trees.
- Dharma, Tolerance, Smṛti, Hindu civilizational memory, attacks-on-Hindus archive, Love Jihad source-aware section, Young Seekers and AUM Verify.
- Responsive design and reduced-motion support.
- Footer credit: Developed by Hari Vissa.

## Validation
TypeScript typecheck was run successfully with `npm run typecheck`.

A production Vite build could not be executed in the model's Linux runtime because the supplied dependency cache contains Windows-native Rollup/esbuild optional binaries rather than the Linux-native binaries. The source itself passes TypeScript type checking. On a normal development machine, run `npm install` and then `npm run build`.
