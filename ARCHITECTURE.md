# AUM architecture

The site is intentionally split so future edits do not require rewriting the whole application.

- `src/data/` — editable knowledge, navigation and content records.
- `src/components/` — visual sections and pages; each chamber is isolated.
- `src/components/ui/` — reusable UI primitives.
- `src/hooks/` — browser/animation capability hooks.
- `src/utils/` — small utilities such as audio.
- `public/assets/` — local images and illustrations.
- `public/media/` — real licensed media (waterfall video goes here).

## Content discipline

For scripture quotations, historical claims, temple history, archaeological claims, court cases and statistics, add an explicit source/evidence status before publication. AUM Verify should never turn an unknown claim into a verified one.

## Hero

The reference composition is preserved: compact AUM header, left editorial hero, central-right 3D ॐ navigation, sacred geometry, temple/water atmosphere and gold/cream typography. The 3D mandala is the actual navigation interface.
